How to use this uploader:

  1. Fill in your GitHub username and repository name
  2. Generate a Personal Access Token with the "repo" scope
  3. Select or drag and drop files to upload
  4. Click "Upload Files" to send them to your repository

Note: This tool uses the GitHub API directly from your browser. Your token is not stored or sent to any server other than GitHub's.
