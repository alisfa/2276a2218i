⚡ Netlify Setup Instructions

  1. Deploy this site to Netlify (drag & drop the folder or connect your Git repository)
  2. In Netlify dashboard, go to Site settings > Environment variables
  3. Add these variables:
    • GITHUB_TOKEN - Your GitHub Personal Access Token
    • GITHUB_USERNAME - Your GitHub username
    • GITHUB_REPO - Your repository name
  4. Your credentials will be securely accessed by the serverless function

How to use this uploader:

  1. Configure the environment variables in Netlify (see above)
  2. Optionally specify a subfolder path for your files
  3. Select or drag and drop files to upload
  4. Click "Upload Files" to send them to your repository
  5. After upload, you'll get direct links to your files
  6. Enable auto-copy to automatically copy the first link to your clipboard

Note: This tool uses Netlify Functions to securely handle your GitHub credentials. They are never exposed to the client-side JavaScript.
